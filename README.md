# SPERMIS-VIT

SPERMIS-VIT is a desktop application for batch image analysis and computer vision detection of spermatozoa stained using the fluorescence vitality technique with Hoechst and propidium iodide. Developed in Python, it integrates a graphical interface, image processing, and report export. For object detection, it uses Ultralytics YOLO and a model trained in-house using YOLO26m as the initial reference. The software achieved 96% reliability compared with a human in object counting and categorization. This application addresses the need for free, lightweight, specialized software that can run on computers with limited resources in laboratories that lack CASA-type equipment or specialized licensed software.
